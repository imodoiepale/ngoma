Lesson notes:

> How it works: We use the hybrid FL2VA/REF2VA model with references to create a consistent character (face and body), add clothing and environment references (cosplay/bedroom) and then we send everything to a Local LLM (Qwen 3.8 27b running in LLama cpp in my case) armed with a foolproof system prompt that will generate custom prompts based on the inputs we provide. We do get plasticky skin in some instances but it's nothing a quick upscale with Klein or Krea can't fix. Even better if you have a LoRA trained already. 
>
> This specifically covers the initial generation tho not the full upscale pipeline.
> Not using the 8steps lora should grant better image quality but will be slower
>
> The most important part in this workflow is the prompting, in my case, the LLM I use for the prompting is running on my second computer on the same network which means I don't need to share VRAM between Comfy and LM studio. 
>
